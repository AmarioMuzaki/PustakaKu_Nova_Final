# PustakaKU Nova
Modern Digital Library Management System

## Isi data demo
Project sudah dilengkapi data contoh:
- 15 buku dari kategori Novel, Programming, Database, Design, Sains, Sejarah, dan Pengembangan Diri.
- 10 anggota.
- 8 transaksi peminjaman dengan status Menunggu, Dipinjam, Terlambat, dan Dikembalikan.
- 3 data denda dengan perhitungan Rp1.000/hari.
- Data favorit dan 4 notifikasi.

## Login demo
- Admin: `admin` / `12345`
- Anggota: `anggota` / `12345`

## Cara menjalankan
1. Extract ZIP.
2. Buka folder di VS Code.
3. Jalankan `index.html` dengan Live Server.
4. Klik **Masuk** lalu gunakan akun demo.
5. Data tersimpan di LocalStorage browser.

## Catatan
Ini adalah versi mini-project frontend. Data belum memakai PHP/MySQL sehingga cocok untuk demo dan presentasi dasar RPL.


## Responsive
Versi ini sudah dioptimalkan untuk desktop, tablet, dan HP. Sidebar berubah menjadi menu off-canvas pada layar kecil, tabel dapat digeser secara horizontal, dan layout kartu/landing page menyesuaikan ukuran layar.
